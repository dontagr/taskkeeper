# Журнал вайбкодера

Личные заметки: что работало с ИИ, что нет.  
Формат из [главы 7](../chapters/07-cycle.md).

**Правило:** пишите **коротко**. 1 запись = 5–10 минут после задачи.  
Особенно полезны: **первый успех**, **первый провал**, **удачный промпт**, **дорогой запрос**.

---

## Шаблон записи (копируйте блок)

```markdown
### YYYY-MM-DD — краткое название задачи

- **Задача:** одно предложение (что должно было получиться)
- **Контекст:** что приложил (spec, тест, файл, границы)
- **Запрос:** суть промпта (не обязательно дословно)
- **Проверка:** команда / тест (например `go test ./internal/httpapi/...`)
- **Итог:** сработало / частично / провал
- **Урок:** 1 фраза — что повторить или не делать снова
- **Повторить промпт?:** да / нет (если да — вставьте удачный фрагмент ниже)
```

---

## Опционально (когда есть время)

| Поле | Зачем |
|------|--------|
| **Инструмент** | чат / Cursor / агент / copilot |
| **Время** | сколько ушло vs оценка «без ИИ» |
| **Лимиты** | сжёг квоту? почему (большой контекст, много итераций) |
| **Ссылка** | PR, тикет, коммит |

---

## Примеры (учебные, Task keeper)

### 2026-01-08 — POST /tasks, итерация 2

- **Задача:** хендлер `POST /tasks` → 201 + JSON task по spec 0001
- **Контекст:** фрагмент spec (статусы, формат ошибок); граница «не трогать storage»
- **Запрос:** «internal/httpapi, только POST, httptest, net/http без либ»
- **Проверка:** `go test ./internal/httpapi/... -v`
- **Итог:** сработало с 2-й итерации (первая — статус 200 вместо 201)
- **Урок:** в промпте явно писать **ожидаемый статус** из spec
- **Повторить промпт?:** да — блок «Spec фрагмент + границы + имя теста»

---

### 2026-01-10 — «Сделай весь сервис» (антипример)

- **Задача:** поднять Task keeper целиком
- **Контекст:** почти нет, только «Go REST»
- **Запрос:** «сделай мне API для задач на go»
- **Проверка:** не дошёл — diff слишком большой
- **Итог:** провал / откат
- **Урок:** один запрос = одна итерация (storage → POST → GET → main)
- **Повторить промпт?:** нет
